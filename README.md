# 62287.com — OCCUR
6-2-2-8-7 spells OCCUR on a phone keypad. Independent hub for planning, budgeting and booking events.

- Static site, generated by `python3 build.py` (edit content there, then rebuild).
- Hosted on GitHub Pages (main branch, root). Weekly auto-refresh via `.github/workflows/auto-refresh.yml`.
- Add YouTube video IDs to `data/videos.json` to embed them on the Video Hub.
- Custom domain: point 62287.com DNS to GitHub Pages (A records 185.199.108–111.153, or CNAME www → webworksa1.github.io), then set the domain in Settings → Pages.
- See `RESEARCH.md` and `PROMPTS.md`.
